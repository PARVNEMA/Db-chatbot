# Natural Language Database Querying Platform Resources

## Knowledge

- [FastAPI Documentation](https://fastapi.tiangolo.com/)
  Primary source for modern async Python APIs, dependency injection, and Pydantic v2 integration.
- [SQLAlchemy 2.0 Async Documentation](https://docs.sqlalchemy.org/en/20/orm/extensions/asyncio.html)
  Authoritative guide for 2.0 select syntax, async sessions, and engine pooling.
- [LangGraph Documentation](https://langchain-ai.github.io/langgraph/)
  Core reference for state machine loops, conditional edges, self-correction nodes, and PostgreSQL checkpointers (`AsyncPostgresSaver`).
- [Cryptography (Fernet) Docs](https://cryptography.io/en/latest/fernet/)
  Symmetric encryption standard used for encrypting and safely storing tenant DB credentials at rest.
- [pgvector-python Documentation](https://github.com/pgvector/pgvector-python)
  Reference for storing and retrieving table/column schema embeddings for intent-based schema linking.

## Wisdom (Communities)

- [LangChain & LangGraph Discord Community](https://discord.gg/langchain)
  High-signal community for agent graph patterns, debugging loop state, and checkpoint persistence.
- [FastAPI GitHub Discussions](https://github.com/fastapi/fastapi/discussions)
  Community for architecture patterns, streaming responses (SSE), and lifespan connection management.
- [SQLAlchemy Discussions](https://github.com/sqlalchemy/sqlalchemy/discussions)
  Expert community for dynamic multi-engine pooling, connection lifecycles, and reflection nuances across dialects.
